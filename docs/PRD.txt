# PRD｜文档自动可视化AI工作流
## 1. 产品概述
### 1.1 产品目标
面向业务运营人员，搭建低代码AI工作流：**上传报表文档，自动解析数据并生成可视化ECharts图表**，降低业务人员做数据可视化的门槛。

### 1.2 用户
- 用户画像：业务运营，能看懂报表，不会写代码、不会ECharts
- 用户痛点：
  - 原始报表格式杂乱，整理数据耗时
  - 不会前端代码，无法快速生成图表
  - 临时数据分析场景多，不值得投入开发资源

## 2. 功能需求
| 模块 | 需求描述 |
|---|---|
| 文件上传 | 用户上传包含业务数据的文档作为输入 |
| 文档提取 | 自动读取文档内文本/表格原始数据 |
| 数据结构化 | LLM清洗、规整原始数据，统一字段格式 |
| 图表生成 | 代码节点生成ECharts图表配置，自动渲染柱状图 |
| 结果输出 | 返回可视化图表，支持查看与复制结果 |

## 3. 工作流设计
开始节点 → 文档提取器 → LLM格式化节点 → 代码节点（ECharts） → 输出节点

## 4. 非功能需求
1. 易用性：业务人员仅需上传文件，无需任何代码操作
2. 可复现：工作流配置可导出/导入，方便迁移
3. 安全性：模型密钥独立配置，DSL不含密钥信息

## 5. 风险与局限
1. 文档排版复杂时，文档提取会丢失部分数据
2. LLM存在幻觉，数据可能出现错误，适合快速预览，不用于高精度财务统计
3. 当前仅支持柱状图，可扩展折线图、饼图

## 6. 迭代规划
V1.0（当前版本）：单文件上传，生成柱状图
V1.1：增加数据校验分支，识别异常数据并提示
V1.2：支持多图表类型选择
V1.3：支持批量上传多文档，合并数据出图

## 7. 验收标准
上传销售报表文档，工作流可正常解析、生成ECharts柱状图，输出可视化结果。
